Razwi Manpower Resources - multi-page website
1. Upload ALL files (including .htaccess) and the images folder to the hosting root (public_html) of www.razwimanpower.in.
2. Turn on HTTPS (SSL). The .htaccess redirects http->https and non-www->www (Apache/LiteSpeed). On Netlify/Vercel/Nginx, set the same redirects, 404 page and cache/security headers in that host's settings.
3. Enquiry forms: emailed to the company through FormSubmit. After upload, send one test enquiry and click the activation link emailed to razwimanpowerresources786@gmail.com (once). See delivery/README_DELIVERY.md for the optional automatic email + WhatsApp setup (Option B).
4. Social links: edit const SOCIAL in site.js.
5. After going live: submit sitemap.xml in Google Search Console, verify Google Business Profile, and add the company's registration/licence numbers where required.
